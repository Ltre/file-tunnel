## 12. 9 月 25—26 日：第二轮功能收敛

初始 Overview 的源码锚点是 `b422e438...`。其后相关开发成果已经合入 `dev/doc-overview`，因此此前仅作为“后续需求”的内容已转为当前实现。

### 12.1 Android 平板 / 宽屏三栏

- 用 `#appShell` 的 `100dvh` flex 高度模型接管主布局；
- 三栏占剩余高度、栏内独立滚动；
- 左栏滚动条收窄；
- 实时媒体控制按钮使用独立样式；
- 260926 进一步按主容器几何对齐宽屏 topbar 左边缘。

这解决了代码层面已定位的平板宽屏向下溢出/底部空白问题，但真实 Android 平板视觉验收仍未完成。

### 12.2 视频转码输出容器

内置 H.265 两个 Profile 的默认输出从 MP4 收敛为 MKV，任务级可覆盖输出后缀；自定义 Profile 缺失 extension 时 HEVC 类编码推断 MKV，其它推断 MP4。非 MP4/MOV/M4V 输出会剔除内置模板中的 `-movflags +faststart`。

### 12.3 Web ZIP manifest、运行方式与路径系统

- 发布包写入/更新单一 `manifest.json`；
- 保存包文件名、隐藏框架、全屏浮层及创建/编辑时间；
- 可选择当前页全屏浮层运行，否则保持独立页/新标签页；
- 文件树支持多级新建，增加 255/1024 字节和 20 层边界；
- 图片/视频/音频、JS/CSS/HTML 可拖入编辑器生成包内引用；
- move/rename 后仅对可确定的 HTML 内部引用安全重写；
- 完整 ZIP 根路径复制、多语言路径编码、M4A/AAC、移动端长按等边界补齐。

### 12.4 Telegram Drive 文件/目录协同

新增独立协同 capability：

- 一次性邀请；
- 邀请摘要预览后再确认加入；
- owner 打开自己的链接不消耗 token；
- 文件/目录 scope 服务端逐请求隔离；
- 成员移除、邀请撤销、停止协同；
- 协同目标删除保护与 move/rename 路径跟随；
- 独立受邀页面及窄屏管理 UI。

这与隧道富文本 `collaborativeEdit` 是两套不同机制。
