# 2026-11：权限、主题、串流恢复与网页更新同步

> 只归纳 `dev/doc-overview` 当前已合入代码，主要依据 `docs/devlog/dev-2611.md`、`server/`、`client/`、`pages/` 和相应测试。

## 11 月 1 日：主题与串流播放器收敛

- 新增 Blamen / Lusns 两款独立首页配色，保留 Classic、Lumen、Orbit、Atelier、Social，默认仍是 Classic。新主题不复制完整后台布局；控制中心切换隧道项仍保持规定的白底。
- 串流观看/操控横屏全屏让媒体填满可用舞台，控件叠加显示并自动收起；播放/静音使用真实点击，修复跨 250ms 状态刷新造成的点击失效。
- 串流台邀请 Markdown 内嵌受限海报与可选当前画面，不授予观看者来源账号和其它隧道资源。网盘分享/协同及静态开放的同一范围内真实移动也走预检与明确确认。

## 11 月 2 日：历史归属与 Markdown 恢复

- Markdown 预览/编辑的等待状态和移动端控制中心圆角调整；同步读取历史时按隧道会话归属，阻止 A 的旧历史在 B 刷新时短暂显示。
- X 帖子图文处理把媒体列表、正文和当前帖子的资源保持一致；“HTTP 抓取成功”不等于所有图片/视频完成，缺失不应从邻近帖子随意填充。

## 11 月 3 日：管理员控制与浏览器日志

- 增加独立浏览器日志管理、后台隧道与设备权限页，支持管理员查看/编辑已知设备的有效能力。选中设备不自动让它成为隧道成员。
- 记录编辑、Markdown 版本、历史删除与当前隧道 ACL 逐项校验。SNS/X 作者用户名与头像按验证来源存储，最后才显示可确定的归属。
- 前端/服务端异常诊断增加独立日志；前台未读与管理员权限灰显不能使用两套冲突的状态推断。

## 11 月 4 日：性能与引用边界

- 调整管理员设备列表/权限面板滚动和前台日志/消息渲染，定位高频更新的界面卡顿；属于特定调用时序修复，不宣称所有 Android/PC 长期内存问题已经解决。
- Markdown 正文在刷新后恢复图片引用及版本校验，不能把同名文件或无授权 URL 当作旧附件。

## 11 月 5 日：多选、编辑、下载表单与串流来源

- 首页传输记录支持多选、批量操作、剪贴板复制；纯文本编辑具有基准版本、未保存防护与失败反馈。
- SNS/YouTube 后台下载表单拆为多个独立草稿标签并允许多选；服务端下载文件名按标题、来源、截取范围及实际后缀规范化。
- 串流节目保存、来源核验和受限预览继续完善，旧保存回执/任务不因刷新被重复创建；批量选台与勾选状态不改变正在观看的节目。

## 11 月 6 日：缓存获取、源网页更新与路由

- “一键获取缺失缓存”有真实任务/结果反馈；消息入口 `existingMessage` 异常路径修复，设备菜单未读状态与通知中心同源。
- 串流后台、小窗、来源跳转和编辑器返回状态分层处理，不能把 UI 收起视为全台播放结束。
- `server/web-zip-credentials.js` 加独立网页编辑签名、`web-zip-sync.js` 保存发布后的待同步事项；创建者/编辑者在转发网页中需验证原记录与授权版本。只有已存在授权来源路径可触发同步，**不会为了同步偷偷加入原隧道**。
- `/tunnel-entry` 改用与主页面一致的七主题路由及公用 `client/tunnel-code-scanner.js`；数据库/网络读取有可用性回退，避免坏的 IDB 请求遮住所有入口。签名二维码仍要原样保留，离开页面停止摄像头。
- 进程异常取证发现 Windows 内存提交量接近系统上限，但没有足够 Node 子进程原生转储定位原因，因此只记录风险与证据，不宣称所有退出已修复。
