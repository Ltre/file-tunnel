## 4. Persisted Infra Audit

2608C 开始把服务端隧道审计落进 `infra.sqlite`。

最初目标：

- 后台即使浏览器离线也能看到 session/device/history/file 统计；
- VClient 有可靠控制面；
- 保存历史 file assets。

但后来高频 sql.js `db.export()` 把首页传输拖慢，形成严重回归。

最终原则：

- audit enqueue；
- batch/flush；
- realtime first；
- audit failure 不能改变传输结果。

这段历史是未来换数据库时的重要经验。
