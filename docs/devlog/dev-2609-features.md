### 版本核对与结论

- 核对用户提供的灰度 `3745d2850b55532a4375f6df2d332f1294f29b5c` 和正式 `1c87fa0091bd8d675fd49b6b31f50ee6f923e007`。两者目录导航和创建的前端流程一致，差异主要是错误提示；正式版本的目录持久化仍为 JSON，灰度已使用 SQLite。因此两边都慢不能直接归因于 SQLite 迁移。
