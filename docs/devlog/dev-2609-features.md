## 55. 2026-09-26：260926-2 顶栏对齐、网页工坊路径及引用更新

- 日志归档：核对 Alpha-2.0.0 所指的 `0de94882` 提交，该版本的 `dev-2608C-features.md` 止于第 51 节；将此后误记的第 52–54 节原文移到本文件，并更新概览索引。保留 2608C 阶段日志，不再把 2609 阶段开发记录写入旧文件。

- 根因：目录上下文新建文件沿用“文件名不得含斜杠”的校验，且原有目录校验没有长度、深度限制；错误只交给顶层 toast，在工坊浮层之下难以看到。新建子文件和子目录现共用校验入口：允许 `/` 分隔相对多级路径，拒绝反斜杠、引号、尖括号及其他非法字符、空段和保留名；完整路径最多 1024 UTF-8 字节、每段最多 255 字节、目录最多 20 层。非法输入通过可见的错误对话框说明原因，冲突和被文件阻挡的路径也给出提示。工具栏新建入口同步复用这套校验；创建后展开新路径的父目录。
