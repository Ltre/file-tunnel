网页 ZIP 编辑手册

创建、编辑、预览和发布 .html.zip 网页包，以及在 ZIP 内正确引用 HTML、JavaScript、CSS 和媒体资源。

1. 核心规则

  • 文件后缀统一使用 .html.zip，ZIP 内应至少有一个 index.html 或其它 HTML 入口。
  • 新建网页、编辑原网页和创建副本都先进入草稿箱。草稿中的修改保存在本机浏览器，只有点击“发布草稿”才会新建或更新隧道文件。
  • 已发布的网页包在专用沙盒中运行，解压结果默认缓存 7 天。沙盒用于运行，编辑时必须先转入草稿箱。
  • 创建设备 ID 作为系统元数据保存，不写入 ZIP。创建设备可直接编辑；其它设备需先获得编辑授权，或创建属于自己的副本。授权申请在通知中心处理。
  • 发布后系统会聚焦到对应的传输记录。网页 ZIP 仍是普通隧道文件，可同步到其它设备或保存到 Telegram 网盘。

2. 建议的目录结构

my-page.html.zip
├─ index.html
├─ assets/
│  ├─ app.js
│  ├─ style.css
│  └─ cover.webp
└─ pages/
   └─ detail.html

ZIP 可以包含多层目录。网页工坊会选取 index.html 作为入口；没有该文件时，使用找到的第一个 HTML 文件。

3. 资源路径

外部 JS、CSS、图片、字体、音视频和其它 ZIP 内资源都会从当前网页包的虚拟目录读取。支持下列写法：

<link rel="stylesheet" href="assets/style.css">
<link rel="stylesheet" href="/assets/style.css">
<script src="assets/app.js" defer></script>
<script src="/assets/app.js" defer></script>
<img src="./assets/cover.webp" alt="封面">
<a href="pages/detail.html">详情</a>
  • assets/app.js 和 ./assets/app.js 相对于当前 HTML 文件。
  • ../shared/app.js 可引用上一级的 ZIP 内目录。
  • /assets/app.js 从该网页包的入口根目录起算，不会读取 Drop2Tunnel 站点根目录中的同名文件。
  • 外部 .js/.mjs 会以可执行 JavaScript MIME 类型返回，支持普通外部脚本和 type="module" 脚本。
  • 绝对网络 URL 需要网络可用且资源服务器允许跨域访问；需离线使用的资源应放入 ZIP。

4. JavaScript 与 CSS 示例

<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <link rel="stylesheet" href="/assets/style.css">
  <script src="/assets/app.js" defer></script>
</head>
<body><button id="hello">测试 JS</button></body>
</html>
// assets/app.js
document.querySelector('#hello').addEventListener('click', () => {
  alert('外部 JavaScript 已执行');
});

defer 可确保外部脚本在 HTML 解析完成后执行。如果不使用 defer，请把脚本放在 </body> 之前，或等待 DOMContentLoaded。

外链脚本标签仍应按 HTML 标准完整闭合，例如 <script src="assets/app.js"></script>。运行层会兼容常见的漏写 </script> 情况，避免其后的页面内容被浏览器吞进脚本节点，但编辑时仍建议使用标准写法。

5. 草稿、预览和发布

  1. 在网页工坊新建草稿，或导入本机 .html.zip；也可从传输记录选择“编辑此网页”。
  2. 使用左侧目录树创建多层目录、上传资源、重命名、删除或拖动移动项目。右键目录（触屏长按）可在当前目录下输入 子目录/文件名 或多级子目录路径；目录最多 20 层，完整路径最多 1024 UTF-8 字节，单级名称最多 255 字节，非法字符会提示原因。也可以点击“从隧道资源浏览器导入”，多选会话资源；导入内容集中放在 ZIP 内的 tunnel-resources/，成功读到完整字节后才写入草稿，读取期间可随时取消。文本修改会自动保存，也可使用 Ctrl/Command + S。
  3. 编辑 HTML 时，可将左侧图片、视频、音频、JS、CSS 或 HTML 文件拖入代码编辑区的光标位置，生成对应的媒体、脚本、样式或页面链接。选中树中的资源后点击“复制路径”，得到从 ZIP 根目录起算、以 / 开头的完整 URL 编码路径；中文、日文等文件名可用于 HTML、CSS 或 JS 引用。
  4. 移动或改名包内资源后，工坊会更新 HTML/HTM 中能明确指向该资源的常见标签属性引用，包括相对路径和以 / 开头的路径；注释、脚本正文、外部链接及无法确认目标的代码不会自动修改。使用 <base href> 的页面仅自动处理根绝对引用，请自行检查其它路径。
  5. 点击“预览”会按当前草稿快照启动独立虚拟目录。预览不会修改隧道文件。
  6. 点击“发布草稿”后才打包 ZIP。新建草稿和副本会创建新传输记录；具备权限的原文件编辑草稿会更新原记录。勾选“发布后隐藏 网页ZIP框架”后，不显示独立页外层标题栏。勾选“是否以全屏浮层打开该网页 ZIP”后，从传输记录点击时会在当前功能首页以全屏浮层运行；不勾选时会打开新标签页，文件图标带有 ↗ 提示。
  7. 发布时会在 ZIP 根目录写入 manifest.json，记录网页 ZIP 文件名、上述两个开关及带时区的创建与最后编辑时间。

6. 运行限制与排查

  • 网页在受限沙盒中运行，不应假设可以读取 Drop2Tunnel 主页的 DOM、Cookie 或页内 JavaScript 对象。
  • 如外部 JS 请求成功但没有效果，先检查控制台语法错误、DOM 是否已创建、引用路径的大小写，以及是否将 type="module" 所需的子模块一并放入 ZIP。
  • 更新 Drop2Tunnel 后首次预览会自动等待新版运行服务完成安装并接管当前页面，无需关闭后再打开。若浏览器长期阻止 Service Worker 安装，页面会给出明确的启动超时提示。
  • 草稿在当前浏览器中保存，清理站点数据可能删除未发布的草稿；重要内容请及时发布或保留 ZIP 副本。
