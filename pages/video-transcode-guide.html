自定义视频转码方案帮助

转码方案是一份 JSON 配置。它定义前端要生成哪些输入项、如何校验这些值、如何把值放进 FFmpeg 参数，以及最终结果的扩展名和下载文件名。服务器始终以独立参数数组启动 FFmpeg，不经过 Shell 拼接命令。

从提交到执行的完整流程

  1. 前端读取所选方案的 fields，动态生成文本、数字、时间、尺寸、下拉框或开关。
  2. 点击“上传并开始转码”后，前端先提交方案 ID、参数和源文件元数据，服务器创建独立任务目录。
  3. 浏览器以二进制流上传源文件；服务器核对声明大小并写入任务目录，不把整个文件读进内存。
  4. 上传完成后任务进入队列。服务器逐步骤替换变量并生成 FFmpeg argv，然后用 shell:false 启动进程。
  5. 多个步骤以前一步输出作为下一步的 INPUT_FILE。中间文件在成功进入下一步后清理。
  6. 最后一步成功后，结果以 output.extension 保存，并按 nameTemplate 生成下载名。任务页可持续查看状态和 FFmpeg 输出。

方案顶层结构

字段含义
id方案唯一 ID，只能使用字母、数字、下划线和短横线，长度 2～64。
name界面显示名称。
description选中方案后显示的说明。
fields动态表单字段数组。
rules跨字段校验。目前支持 requireAny。
steps一到十个顺序执行的 FFmpeg 步骤。
output最终文件扩展名与下载名称模板。

fields：动态表单参数

字段名必须为大写字母开头的 A-Z0-9_ 标识。支持类型：

类型表单与校验
text普通文本。
number数字，可配 min/max。
duration秒数或 HH:MM:SS.mmm。
scaleFFmpeg 尺寸格式，例如 1920:-2。
select从 options 中选择。空字符串选项在界面显示为“默认”。
boolean复选框；选中值为 1，未选中为空。

label 是显示名称，default 是默认值，placeholder 是输入提示，required:true 表示不能为空。

rules：跨字段校验

{ "type": "requireAny", "fields": ["START_TIME", "END_TIME"], "message": "至少填写一个时间" }

这表示列出的字段至少有一个非空。单字段必填直接使用字段的 required。

steps 与参数组装

每一步必须含有输入变量和 ${OUTPUT_FILE}。字符串是一个完整 argv；请勿把多个参数写进同一字符串。

{
  "name": "H.265 转码",
  "args": [
    "-i", "${INPUT_FILE}",
    "-c:v", "libx265",
    { "when": "CRF", "values": ["-crf", "${CRF}"] },
    { "when": "PRESET", "values": ["-preset", "${PRESET}"] },
    "-movflags", "+faststart", "-c:a", "copy",
    "${OUTPUT_FILE}"
  ]
}

带 when 的对象是可选参数组：对应字段非空时才把 values 加入命令。因此“编码速度”选择“默认”时不会生成 -preset。

系统变量

变量值
${INPUT_FILE}当前步骤输入；第一步是上传源文件，后续步骤是上一步输出。
${ORIGINAL_INPUT_FILE}始终指向最初上传的源文件。
${OUTPUT_FILE}当前步骤由服务器分配的输出路径。
${BASENAME}源文件名去除扩展名后的部分。
${EXT}当前输出扩展名。

多步骤方案

在 steps 中按顺序放入多个对象即可。非最后步骤使用 MKV 中间容器，最后步骤使用 output.extension。每一步都必须明确读入和写出文件；任一步退出码非 0 或没有生成输出文件，整个任务失败，后续步骤不会执行。

output：结果文件

"output": { "extension": "mp4", "nameTemplate": "${BASENAME}-h265.${EXT}" }

扩展名只允许系统白名单中的媒体格式。文件名模板可使用 BASENAME 和 EXT，非法文件名字符会由服务器替换。

完整自定义示例

{
  "id": "h265-web",
  "name": "网页播放 H.265",
  "description": "可选截取、缩放和 preset，复制原音轨",
  "fields": [
    {"name":"START_TIME","type":"duration","label":"开始时间"},
    {"name":"END_TIME","type":"duration","label":"结束时间"},
    {"name":"SCALE","type":"scale","label":"输出尺寸","placeholder":"1920:-2"},
    {"name":"CRF","type":"number","label":"CRF","default":"28","min":0,"max":51},
    {"name":"PRESET","type":"select","label":"编码速度","default":"","options":["","fast","medium","slow"]}
  ],
  "rules": [],
  "steps": [{
    "name": "转码",
    "args": [
      {"when":"START_TIME","values":["-ss","${START_TIME}"]},
      "-i","${INPUT_FILE}",
      {"when":"END_TIME","values":["-to","${END_TIME}"]},
      "-c:v","libx265",
      {"when":"CRF","values":["-crf","${CRF}"]},
      {"when":"PRESET","values":["-preset","${PRESET}"]},
      {"when":"SCALE","values":["-vf","scale=${SCALE}"]},
      "-movflags","+faststart","-c:a","copy","${OUTPUT_FILE}"
    ]
  }],
  "output":{"extension":"mp4","nameTemplate":"${BASENAME}-web.${EXT}"}
}

输入、输出与缓存

每个任务在服务器转码缓存根目录中使用独立随机目录。源文件、中间文件和结果不会与其它任务混用。取消任务会终止 FFmpeg；任务删除会连同目录一起删除。缓存清理区可分别清理浏览器中与转码接口有关的失效缓存、服务器孤立/失败缓存，或全部已结束任务缓存。

清理“全部已结束缓存”会删除已完成任务的结果文件，任务记录仍会保留并标记结果缓存已清理，但不能再下载。

安全边界与排错

  • 方案只能使用声明过的字段变量；未知变量会被拒绝。
  • 参数逐项传给 FFmpeg，不能使用管道、重定向或 Shell 命令。
  • 查看任务的“FFmpeg 输出”可判断编码器、参数或媒体流错误；自动刷新会保留手动展开状态。
  • 如果任务停在“等待上传源文件”，说明浏览器上传未完成；停在队列说明前序任务仍在执行；退出码错误则查看最后几行 FFmpeg 输出。
