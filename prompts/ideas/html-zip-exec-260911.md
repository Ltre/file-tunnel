答（最终版）：




    10、隧道需要支持新的文件类型“网页 ZIP 包”，文件后缀统一使用 `.html.zip`。

        10.1、在连接设备区域的汉堡键 `button#connectionHeaderMenuBtn` 菜单中新增“网页工坊”。点击后全屏打开“网页工坊”浮层，提供“创建网页”和“草稿箱”等功能；草稿箱以列表形式展示现有草稿，并支持编辑、删除、预览、发布。

        10.2、新建网页时，先在网页工坊的草稿箱中创建草稿。草稿提供页内离线简易文件目录管理器，可上传资源、创建/修改/删除目录、编辑代码和文本等；草稿中的 ZIP 展开数据及其所有变更仅保存于草稿箱专属的浏览器缓存区域，整个编辑过程支持离线使用。

        10.3、打开隧道中已有的 `.html.zip` 文件时，可以将 ZIP 展开到该文件专用的浏览器沙盒中，用于快速运行其中的网页，展开数据默认缓存 7 天。沙盒仅用于运行网页，不直接承担编辑功能；如需修改其中内容，必须先将其转入草稿箱，再在草稿箱中编辑。

        10.4、每个网页 ZIP 包需要在系统侧记录关联的“创建设备 ID”，该信息属于系统元数据，不写入 `.html.zip` 文件本身。默认只有创建设备拥有编辑权限；其它设备如需编辑，必须先向创建设备申请编辑权限，或创建一份归属于自己的网页 ZIP 副本后再编辑。

        10.5、当其它设备申请某个网页 ZIP 包的编辑权限时，创建设备应在新开发的消息中心页面 `/notification` 中收到并查看该申请通知，并可据此处理编辑权限申请。

        10.6、不论是新建网页，还是编辑已有网页 ZIP 包，都必须先在草稿箱中进行。草稿中的所有修改只影响草稿箱专属缓存，不会实时修改隧道中的网页 ZIP 文件；只有执行“发布草稿”时，系统才将当前草稿重新打包成 `.html.zip` 文件，并根据草稿来源和权限决定发布方式：

            * 新建网页或基于原网页创建自己的副本：向隧道发送一个新的网页 ZIP 文件；
            * 编辑自己创建的网页 ZIP，或已获得原创建设备编辑权限的网页 ZIP：更新隧道中指定的原网页 ZIP 文件记录。

        10.7、草稿发布完成后，页面应自动 Focus 到传输记录中本次新建或更新的目标网页 ZIP 文件所在锚点，方便用户立即定位发布结果。

        10.8、网页 ZIP 包仍作为普通隧道文件参与传输，可同步给其它设备，也可以保存到 Telegram 网盘。用户也可以在设备其它位置自行创建并打包 `.html.zip` 文件后，再发送到隧道。
