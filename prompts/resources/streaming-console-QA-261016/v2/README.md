# 串流控制台原型 v2

入口：[index.html](index.html)（离线打开，可点击标有操作的按钮浏览页面）。

共 26 张状态原型，每张包含 SVG 与 PNG；总览为 `00-overview.png`。

## 本版交互约定

- PC：控制台为独立非阻塞窗口，原首页三栏继续保留；收起回到完整三栏。
- 顶栏：基于当前首页现有四个常驻功能按钮与右侧离开按钮，只增加串流恢复入口；网盘、网页工坊和音乐等条件按钮仍按既有状态显隐。示例采用默认主题与默认顺序。
- 移动端：全局顶栏和原底部三个按钮可用；控制台独立于三栏侧滑。串流前台时不将任何原栏位标为控制台。
- 切换界面只改变显示焦点，不主动停流、退订或重建会话。
- 来源选择器：只在选择器中勾选候选资源，跨渠道保留待导入清单，确认后返回创建页。
- 已导入播放列表：没有勾选框，使用拖动手柄、上移下移或名称排序排列。
- 同台共享：当前项、播放状态与目标进度同步；本机音量、静音及暂停本机观看独立。恢复本机观看时追随台当前状态。
- 下线保留订阅；公开改仅限邀请需确认踢出旧接收端，并重新授权。

## 交互路径

首页入口 01 → 管理 02 → 创建 03 → 导入 04/05/06/07 → 回到创建 03 排序 → 管理 02。

发现 08 → 播放 09 → 其他预览 10 / 方阵 11 → 放大 12 → 还原 11。

收起控制台 → 首页 15 → 顶栏串流恢复入口 → 控制台 02。

移动端共存与切换见 16，导入排序见 17，文件/直播/监控见 18。

权限与恢复见 13/19；采集配置 14 → 屏幕授权 20 / 摄像头授权 21 → 返回配置或启动台。

监控主动媒体全屏见 22；随机隧道记录挑选见 23。

## 页面目录

- [01 从首页菜单进入](01-home-entry.png) — 保留首页三个原栏位与当前顶栏；只在连接设备菜单内新增串流控制台入口。
- [02 PC · 独立控制台窗口](02-console-window.png) — 窗口外可操作首页；收起按钮立即恢复完整三栏，顶栏串流图标一键恢复。
- [03 创建串流台 · 已导入与排序](03-create-playlist.png) — 已导入区没有勾选框；导入打开独立选择器，排序只作用于确认导入后的播放列表。
- [04 统一导入 · 本机文件](04-import-local.png) — 选择器内完成跨渠道挑选；底部待导入清单保留其他渠道的选择，确认后返回创建页。
- [05 统一导入 · 网盘文件](05-import-drive.png) — 一个或多个文件通过勾选选择；随机抽取是另一种挑选方式，仍需确认导入。
- [06 统一导入 · 隧道文件与记录](06-import-tunnel.png) — 单条或多条记录可展开后选择其中的可预览资源；加入待导入清单后再统一确认。
- [07 随机网盘文件 · 抽取后确认](07-import-random.png) — 随机抽取产生候选项；仅勾选项加入待导入清单，确认后返回同一播放列表。
- [08 自动发现与订阅](08-discover-subscribe.png) — 发现范围是同隧道或已关注设备；公开台可订阅，仅限邀请台通过有效邀请加入。
- [09 同台同步播放与接收状态](09-synced-player.png) — 共享控制明确标识作用范围；音量与静音属于本机。收起控制台不会退出观看。
- [10 音频、图片与文本预览](10-media-previews.png) — 四个独立台的预览示例；每个台仍只有一个共享当前项，文本阅读滚动由本机操作。
- [11 监控大爷模式 · 窗口](11-monitor-wall.png) — 批量操作默认作用于本机观看；全台播放控制通过单台详情执行。
- [12 监控方阵 · 放大与还原](12-monitor-expanded.png) — 放大仍保留全局顶栏和收起按钮；媒体全屏为额外主动操作，退出后回到此界面。
- [13 可见性与邀请管理](13-visibility-invitation.png) — 公开改仅限邀请需要明确确认踢出当前接收端；下线保留订阅，两个动作分别说明。
- [14 摄像头与屏幕来源](14-camera-screen.png) — 实时来源单独配置；只有发起设备主动开始采集后才启动，不显示文件进度条。
- [15 回到首页 · 串流继续](15-home-background-streams.png) — 三个原栏位完整可操作；点击顶栏新增的串流图标恢复控制台，上次输入与编辑内容保留。
- [16 移动端 · 控制台与原三栏切换](16-mobile-switching.png) — 底部始终保留原三个按钮；串流前台时不高亮其中任何一栏，顶栏串流入口可随时恢复控制台。
- [17 移动端 · 选择、导入与排序](17-mobile-import-sort.png) — 三个状态分别表示导入选择器、已导入队列和排序结果；排序区不出现资源勾选框。
- [18 移动端 · 播放、实时源与监控](18-mobile-player-monitor.png) — 三个独立预览状态；文件支持进度与快进快退，实时源仅显示 LIVE，底部首页功能始终可切入。
- [19 邀请、下线与恢复状态](19-connection-recovery.png) — 订阅下线台保留位置；权限撤销需重新获邀；来源不可用提供重新选择入口。
- [20 屏幕捕获 · 浏览器授权与返回](20-browser-share-permission.png) — 系统选择器为示意；确认或取消均返回发起端来源配置，权限对话框内不触发首页侧滑。
- [21 摄像头 · 本机授权](21-camera-permission.png) — 摄像头启动使用浏览器站点授权；屏幕共享另走屏幕选择器，取消仍保留已保存的台配置。
- [22 监控方阵 · 主动媒体全屏](22-media-fullscreen.png) — 只有主动媒体全屏隐藏全局导航；退出回到放大方阵，也可直接返回首页，串流继续。
- [23 随机隧道记录 · 抽取后确认](23-random-tunnel-import.png) — 保持隧道文件渠道；先抽取记录内可预览资源，再勾选候选项，跨渠道合并确认。
- [24 监控方阵 · 九宫格](24-monitor-nine-grid.png) — 九宫格与四宫格分别保留各自布局；离线台仍占原位置，批量操作作用于本机观看。
- [25 屏幕共享 · 开始前配置](25-screen-source.png) — 屏幕共享有独立来源配置；取消浏览器选择器返回此页，摄像头的选择与授权保持独立。
- [26 摄像头 · 已启动与后台运行](26-camera-live.png) — 授权后显示实时预览及接收端状态；收起只隐藏控制台，停止本台才结束采集和发送。

本目录均为设计产物。原型中的页面跳转与排序状态示例不代表功能已开发完成，应用代码未在本次任务中修改。
