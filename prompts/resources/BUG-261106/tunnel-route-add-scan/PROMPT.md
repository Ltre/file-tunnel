10、隧道路由界面新增 `扫描隧道码` 组件，支持扫描隧道码进入对应隧道，并根据是否存在已加入的隧道记录，显示两种界面状态。

   七个主题统一按以下路径引用原型，`{主题名}` 分别为 `Lumen`、`Orbit`、`Classic`、`Atelier`、`Social`、`Blamen`、`Lusns`：

   ```text
   已加入隧道：
   D:/Workspace/github/Ltre/file-tunnel/prompts/resources/BUG-261106/tunnel-route-add-scan/{主题名}/tunnel-route-add-scan.svg

   未加入任何隧道：
   D:/Workspace/github/Ltre/file-tunnel/prompts/resources/BUG-261106/tunnel-route-add-scan/{主题名}/tunnel-route-add-scan-none.svg
   ```

   严格按照各主题最新 SVG 实现布局和配色，具体要求如下。

   **两种状态共用的上半部分：**

   - 顶部为横向展开、四角圆润的 header，火箭图标与 `Drop2Tunnel Studio` 组成一个整体，居中显示。
   - 主体水平居中，依次排列 `加入数据隧道` 标题、`输入朋友提供的暗号，或扫描隧道码` 说明，以及五个横向等宽、间距一致的暗号输入框。
   - 输入框使用中性底色、圆角及约 `1px` 的柔和细描边。
   - 输入框下方单独放置一行 `扫描隧道码` 按钮，宽度与五个输入框的整体宽度基本一致。扫描图标位于文字左侧，图标和文字整体居中；按钮使用中性底色、圆角和柔和细描边。
   - 上述组件在两种状态下的位置、尺寸及间距保持一致，不因下方内容不同而整体上下移动。

   **已加入隧道状态：**

   扫描按钮下方留出明显间距，居中显示 `或进入已加入的隧道`。再下方放置一个比扫描按钮更宽、带轻薄描边的圆角组合框，内部从上到下排列：

   ```text
   [       已加入隧道的下拉选择框       ▾]
   [             进入所选隧道            ]
   [       我没有暗号，创建一个隧道       ]
   ```

   三个控件等宽、左右对齐，纵向间距紧凑均匀。下拉框保留独立细描边，**当前选中项的短码与备注作为整体，相对于整个 select 组件水平居中**；下拉箭头保留在右侧，不随文字移动，也不使文字偏离组件中心。

   **未加入任何隧道状态：**

   扫描按钮下方留出间距，直接显示独立的 `我没有暗号，创建一个隧道` 按钮，与扫描按钮等宽、左右对齐。

   不显示 `或进入已加入的隧道`、隧道下拉框、`进入所选隧道` 按钮及组合框，也不为这些组件保留空位。

   **配色与适配：**

   - `进入所选隧道` 使用所在主题的第一主色。
   - 创建按钮以最新 SVG 为准：Lumen／Lusns 保留已确认的淡色；其余五个主题使用 **20% 进入按钮主色＋80% 主题面板底色**，使其属于同一色系，但色彩强度弱约 80%。渐变按各色标分别混合。文字保持清晰，不通过降低整个按钮透明度来淡化。
   - header 使用与主题协调的独立底色或渐变，不直接套用第一、第二主色。所有描边保持柔和，不使用厚重边框。
   - SVG 的 `900×700` 是参考画布，不是页面固定尺寸。宽窄屏均需适配，保持上述排列和对齐关系，并继续保留轻量隧道路由的资源加载策略。
