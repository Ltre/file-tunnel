# ORBIT 反馈修订

本轮只修改 UI-261026 内的皮肤、静态原型和生成资料；未修改产品源码。原版尺寸、布局、字段及业务操作沿用现有实现。

| 用户图号 | 界面 | 本次处理 |
|---|---|---|
| 1 | 资源浏览器／宽屏 | 补齐文件名、统计、挂载区、引用区、状态标签与动作按钮的深色表面及文字层次。 |
| 2、4 | 隧道设置／窄屏、宽屏 | 面板和内容区统一深色；提示、权限项、管理项、按钮及禁用态分别设置可辨认的颜色。 |
| 3、10 | 树形目录选择器／窄屏、宽屏 | 目录区域改为深色，正常节点与选中节点均使用对应文字颜色；保留树结构、滚动及目录操作。 |
| 5 | 富文本预览 | 正文和顶栏使用深色表面，正文继承清晰的浅色文字；不批量改写用户内容中的显式格式。 |
| 6 | 记录菜单 | 菜单与按钮使用不同明度的深色；按钮边界仅保留低透明度描边，单色串流图标同步提亮。 |
| 7 | 设备详情二维码 | 增加白色留白边缘与轻柔外框、阴影；保持二维码图案完整，不裁剪或反色。 |
| 8 | 控制中心 | 增加到 12 条示例隧道，触发原有列表溢出规则和上下滚动按钮；只在设计预览中恢复这两个按钮的滚动响应。 |
| 9 | 备份对话框 | 提示文字适当提亮，仍弱于标题与主要按钮。 |

## 核对方法

- 按 1440×1000、390×844 检查上述对应组件的实际颜色，并重新生成全部设计图。
- 对可读文字补查颜色对比；控件位置核对只证明保存的快照没有被皮肤移动，不能替代颜色与人工看图。
- 控制中心示例列表实际溢出，核对下滚动及上滚动按钮能改变列表位置。产品源码本就包含这些按钮，只在列表溢出时显示；前版仅有两条示例数据，未展示此状态。
- `feedback-check.json` 为表面颜色及滚动检查；`contrast-check.json` 为本次重点文字抽样；`render-report.json`、`gallery-check.json` 为出图及入口检查。
