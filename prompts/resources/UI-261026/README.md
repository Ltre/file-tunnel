# Drop2Tunnel 前台视觉换肤 · 261026

双击 `index.html` 打开设计总览。两套候选分别为 `lumen`（棱镜白）和 `orbit`（紫夜电光）；`offset` 根据反馈退出候选。

## 查看方式

- `index.html`：整套总览、五大功能入口、分支界面和手机稿。
- `prototype.html`：按界面／设备尺寸查看，可用底部左右箭头切换方案，用“原版对照”查看同一份 DOM 的原始样式。
- `comparison.png`：两套方案的主要界面对照。
- `detail-comparison.png`：清理垃圾缓存与传输记录详情的重点对照。
- `lumen/overview.png`、`orbit/overview.png`：各自的整套桌面总览。
- 各方案的 `desktop/`、`mobile/`：独立 PNG 图片。
- `interaction-tree.md`：从入口逐层展开的操作树、图稿位置和条件分支。

## 方案

**LUMEN · 棱镜白**：白色主表面、紫蓝操作信号和青色辅助状态；用薄边框、轻阴影、局部浅色底组织高密度组件。重点是明亮而清晰，避免大面积重玻璃和渐变色块压住内容。

**ORBIT · 紫夜电光**：深墨色底、紫青色信号、分层的低亮度表面；播放器和工作台共用一套语义。危险操作、次级文字和选中项分别控制对比，避免所有按钮都发光。

## 边界与基线

这是视觉设计稿，不是正式系统改造。只在本目录内增加设计资源和生成脚本。产品源码、接口、流程、路由、业务存储、Git 暂存状态不由本设计改动。

源布局来自生成时工作区的 `pages/index.html`、`app.js` 与对应前端模块，包含当时未提交的实现。布局与内容用隔离样本填充；网页工坊与串流等使用原模块渲染。皮肤在 `assets/skins.css`，只涉及颜色、背景、阴影、边框颜色、圆角、焦点和视觉效果，未定义新的宽高、布局顺序、间距、断点或手势。

首页工具在初始化后移入隧道设置；首页三栏、既有顶栏按钮、移动三工作区、网盘与工坊及串流全屏浮层均沿用当前结构。串流导入选择与已导入资源排序保持两个界面。

旧功能截图只用来补查分支。清理垃圾弹窗和详细数据页按最新源码结构出稿：未增加不存在的分类、勾选器、按钮或操作步骤。用户创作网页、原照片／视频等内容本身不跟随系统皮肤重绘。

## 验证说明

本轮 ORBIT 十项反馈修订可打开 `orbit-review.html` 按图号查看；具体处理见 `review-feedback.md`。重点文字、表面颜色和控制中心滚动的核对分别保存在 `contrast-check.json` 与 `feedback-check.json`。控制中心改用 12 条隔离示例隧道，展示现有列表溢出时的上下滚动按钮，未修改产品实现。

`source-baseline.json` 记录本轮读取的源码哈希；`render-report.json` 记录图稿尺寸、生成范围及几何核对。`layout-geometry.json` 是各方案控件位置的核对数据。

原型中的产品画面为静态只读 DOM；外层方案切换、选择界面和尺寸控制属于设计评审器。它没有接入正式账号、真实设备或正式 Telegram。交互树的条件分支明确标记；本轮不宣称完成业务、真实网络或硬件回归。

## 文件说明

`snapshots/` 是可离线预览的界面快照；`assets/source.css` 是当前项目样式的设计副本；`scripts/` 为本目录的生成工具。运行数据限制在 `_runtime/`，不作为生产配置。

重新生成视觉图：

```text
node prompts/resources/UI-261026/scripts/capture.cjs
node prompts/resources/UI-261026/scripts/render.cjs
node prompts/resources/UI-261026/scripts/build-gallery.cjs
```

生成器使用本机现有 Chrome 与 Codex 自带的 Playwright／Sharp；不安装依赖、不修改项目脚本。`capture.cjs` 会启动仅使用隔离数据的本机渲染环境。
