# 前台操作树与换肤覆盖

本文件按「入口 → 可操作位置 → 下一层界面 → 最终结果」展开，重复界面回指已有节点。用于设计覆盖审阅，不是产品功能通过验收的声明。

- **有图**：目录中的同名 PNG 和 `snapshots/*.html` 使用当前源码组件生成。
- **复用**：返回已列出的界面，或共享相同的输入、确认、提示、选择器组件。
- **系统边界**：系统文件选择器、浏览器权限、第三方认证、操作系统分享等，保留现有入口，不绘制成自研产品界面。
- **条件分支**：需要另一台真实设备、真实登录方式、授权或外部服务；以源码和历史功能截图补查，未宣称已完成真实环境验收。

图名在两套候选目录中相同。`offset` 已退出候选。

## R · 隧道路由入口

1. 入口页（`route`，有图）
   - 五位暗号输入 → 逐位输入／退格／粘贴 → 请求加入 → 功能首页。
   - 暗号不正确／隧道不存在／无权限 → 原位置的错误提示 → 再次输入。
   - 已加入隧道下拉 → 选择隧道 → 功能首页。
   - 继续最近使用的隧道 → 功能首页。
   - 创建隧道 → 生成新会话 → 功能首页。
   - 附近设备存在时的设备入口 → H2 设备资料（条件分支）。
2. 功能首页的短码下拉／移动端隧道入口 → 切换隧道与控制中心（`home-control-center`，有图）
   - 隧道列表 → 当前项关闭；其他项切换。
   - 存在进行中传输 → 原有切换确认 → 继续／取消。
   - 控制中心功能块 → 回指 H1、H2、D、W、S。
   - 拖动功能块 → 调整控制中心顺序；保留现有分界与收起行为。
   - 关闭／点击遮罩 → 回原工作区。

## H · 功能首页

### H1 · 顶栏与设置

1. 首页三栏（`home`，有图）：连接设备 → 传输记录 → 协同编辑，顺序与宽度规则沿用当前 CSS。
2. 顶栏按钮顺序：刷新、磁链缓存、主题、设置、已最小化网盘／工坊／串流、音乐恢复；最右暂时离开。
   - 刷新 → 原有应用资源更新与刷新；运行结果属于系统／业务边界。
   - 磁链缓存 → 既有下载缓存页／嵌入页 → 记录列表、恢复、缓存清理；外层与按钮皮肤共用，未重做下载策略。
   - 主题 → 既有快速主题菜单 → 当前四种主题；设计评审器中的方案切换与产品主题菜单不是同一个控件。
   - 设置 → 隧道设置（`home-settings`，有图）。
     - 隧道工具：发送文件夹、同步目录、粘贴板共享、清理垃圾、资源浏览器、备份／导入、修改短码。
     - 发送文件夹 → 系统选择 → 既有发送过程／进度／取消。
     - 同步目录 → 系统目录授权 → 镜像状态／停止；文件系统权限属于系统边界。
     - 粘贴板共享 → 权限 → 开启／关闭、收到共享内容、复制。
     - 清理垃圾 → H5。
     - 资源浏览器 → H4。
     - 备份／导入 → H6。
     - 修改短码 → 原有文本输入与权限检查 → 成功／失败提示。
     - 增强局域网 P2P → 原有媒体权限流程与状态；条件分支。
     - 通话铃声 → 预置选择／试听／自定义文件；系统文件选择器作为边界。
     - 权限设置 → 原有勾选项／保存 → 成功／失败提示。
     - 管理设备 → 在线选择／输入设备 ID → 添加／权限／移除；需真实设备的结果为条件分支。
   - 最小化应用图标 → 恢复 D、W、S；只保留当前已有的出现条件。
   - 音乐恢复 → H3 媒体播放器与队列。
   - 暂时离开 → 返回 R，保留原有数据语义。

### H2 · 连接设备与汉堡菜单

1. 汉堡菜单（`home-menu`，有图）
   - 扫描隧道码 → 摄像头权限／扫码画面／扫描结果 → R／H（条件分支）。
   - 接收光媒 → 既有接收界面 → 摄像头或网络恢复／进度／结果（条件分支）。
   - 资源浏览器 → H4。
   - 网页工坊 → W。
   - 串流控制台 → S。
   - 通知中心（`home-notifications`，有图）→ 全部／未读状态、已读、删除、邀请接受／拒绝 → 原业务目标。
   - Telegram 网盘 → D。
2. 当前短码 → 复制／选择已加入隧道 → R2。
3. 输入其他短码 → R1 的加入及错误状态。
4. 设备行／关注设备／附近设备 → 设备资料（`home-device`，有图）
   - 备注 → 原有编辑弹窗 → 保存／取消。
   - 关注／取消关注 → 原列表状态更新。
   - 设备主页／二维码 → 既有设备入口（条件分支）。
   - 语音通话 → 呼叫／接听／拒绝／挂断／权限错误（条件分支）。
   - 对讲 → 目标选择／开启／停止（条件分支）。
5. 附近设备增强发现 → 位置授权／拒绝／发现结果（系统与设备条件分支）。
6. 摄像头／语音聊天／全局对讲 → 既有媒体控件与参加状态（条件分支）。
7. 退出 → 原有清理说明和确认 → 进度／结果 → R。

### H3 · 传输记录、详情与媒体

1. 记录列表（`home`）
   - 顶部／底部跳转 → 同列表不同位置；不新增记录导航。
   - 文件拖入／选择文件 → 系统选择 → 发送模式／上传进度／取消／错误。
   - 消息输入 → 发送；MD → 原有 Markdown 编辑／预览／插入媒体／发送。
   - 图片粘贴入口 → 原有识别、预览与发送；浏览器授权属于系统边界。
2. 通用记录菜单（`home-record-menu`，有图）
   - 详情 → H3.3。
   - 复制锚点／复制文本 → 剪贴板结果提示；动作叶子。
   - 收藏／取消收藏 → 原有徽标状态；动作叶子。
   - 备注 → 文本编辑 → 保存／取消；复用文本弹窗。
   - 转发至其他隧道 → 既有隧道选择／目标确认 → 结果；复用选择器。
   - 文件／合辑的光媒分享 → H2 光媒流程。
   - 创建串流台／添加到串流台 → S2／S3。
   - 保存到网盘 → 账号选择 → 分区／目录选择 → 转存状态 → D。
   - 网页 ZIP 的编辑入口 → W3。
   - 清理缓存／还原／删除等按记录类型出现的动作 → 原有确认、进度和错误；保持数据语义。
3. 详细数据（`home-details`、`home-details-sns`、`home-details-raw`，有图）
   - 记录 ID、关联隧道、发送者、时间、备注 → 保留实际字段。
   - 文本／Markdown 正文或富文本摘要 → 原有内容展示。
   - 文件信息 → 大小、类型、缓存状态、文件 ID；合辑复用多条文件信息。
   - SNS 文件／来源信息 → 原链接、获取状态、进度、生成记录定位。
   - 原链接 → 外部页面；不换肤第三方站点。
   - 获取文件内容 → 既有任务／错误／完成；外部服务条件分支。
   - 定位生成记录／来源记录 → 回指记录列表。
   - 记录元数据 → 展开／收起 JSON（`home-details-raw`）。
   - 定位到记录 → 关闭详情并定位；复制记录链接 → 剪贴板；关闭 → 原列表。
4. 富文本预览（`home-rich`，有图）→ 引用媒体／历史／编辑权限／编辑器／关闭；按原记录与权限出现。
5. 单文件预览 → 上一个／下一个、缓存／下载、元数据、全屏、远程、音乐、光媒等按媒体类型出现的原控件。
   - 图片 → 原有缩放／查看／全屏／返回。
   - 视频／音频 → 播放／暂停／进度／音量／全屏／浏览器阻止自动播放状态。
   - 未缓存／正在恢复／失败 → 原有恢复入口、进度及重试。
   - 远程预览 → 选择被控设备 → 等待／拒绝／进入全屏 → 远程控制浮层／最小化气泡／退出（真实第二设备条件分支）。
   - 音乐播放器 → 当前曲目、播放控制、队列、收藏／队列操作；使用既有布局。
6. 合辑 → 合辑预览 → 网格／单文件 → 上一个／下一个／全屏／返回合辑；与 H3.5 回指。

### H4 · 资源浏览器

资源浏览器（`home-resources`，有图）→ 刷新／最小化／关闭 → 筛选、排序、文件列表、引用位置与缓存状态 → 单文件预览／定位引用／缓存或清理／选择及批量动作。预览与清理回指 H3、H5，避免为同一个组件重复发明布局。

### H5 · 清理垃圾

设置中的“清理垃圾” → 扫描中 → 无可清理缓存，或命中列表（`home-cleanup`，有图）→ 取消／清理 N 项 → 现有清理结果。

当前组件只有标题、统计说明、最多 20 条预览、剩余项说明和动作按钮。没有新增分类、勾选器、独立统计卡片或额外确认步骤。旧截图只用于确认存在这个分支，视觉按当前两套方案独立处理。

### H6 · 备份与导入

备份／导入（`home-backup`，有图）→ 导出元信息／导出完整备份／导入备份 → 系统下载或文件选择 → 原有确认、进度、结果。未将备份数据发送到设计预览器。

### H7 · 协同编辑

富文本编辑器 → 粗体／斜体／下划线／列表 → 插入图片的系统选择 → 引用文件选择与路径 → 文本／媒体内容 → 清空确认、发送 Markdown 副本、发送富文本。权限受限、同步中、已同步等状态使用原位置；不增加新编辑器、侧栏或编辑模式。

## D · 网盘

1. 网盘入口（`disk`，有图）
   - 未登录 → 现有账号面板 → 添加账号／认证／返回；Passkey 与第三方认证属于系统边界。
   - 当前账号 → 账号设置；切换／添加（`disk-accounts`，有图）→ 选择账号／登录／移除的二次确认／取消。
   - 分区选择 → 切换分区；设置（`disk-partitions`，有图）→ 当前已有的新建、重命名、复刻、删除／恢复等子流程，按权限保留。
   - 刷新／最小化／关闭 → 原有生命周期。
2. 路径与工具栏
   - 面包屑 → 上级／根目录；编辑路径 → 输入／确认／错误。
   - 搜索当前目录／全盘／附加挂载协同 → 结果／无结果（`disk-empty`，有图）。
   - 排序键、升降序 → 同列表；列表／网格（`disk-grid`，有图）。
   - ＋ → 上传文件／新建目录（`disk-dialog`，有图）／新建文件 → 系统选择或原有编辑器。
3. 文件／目录／挂载行
   - 目录 → 同组件递归进入下一级；挂载 → 协同授权作用域，原面包屑与回退语义保留。
   - 文件预览 → 图片／音视频／文本，类型特有工具、缓存、下载、分享；同类媒体控件复用。
   - 选择／多选（`disk-selection`，有图）→ 批量移动、删除、取消选择；背景菜单含原有全选／反选／分享。
   - 行操作菜单（`disk-menu`，有图）
     - 预览、编辑文件、下载并缓存 → 相应媒体／文本／HEX 编辑器及原有保存语义。
     - 重命名 → 文本弹窗。
     - 复制／移动（`disk-transfer`，有图）→ 分区／目录树 → 展开／选择／新建目标目录 → 确认／取消／任务。
     - 防失联检测 → 原有进度与检查结果。
     - 复制路径 → 剪贴板动作叶子。
     - 属性（`disk-properties`，有图）→ 大小、位置、审核、时间等实际字段。
     - 缓存到浏览器／清理缓存 → 原有任务、错误、确认；原文件与缓存删除语义不变。
     - 复制到协同项目 → 可写项目选择 → 目标树 → 转存结果；无可写项目显示原错误。
     - 邀请协同／管理协同（`disk-collaboration`，有图）→ 角色、期限、链接、成员、加入确认、撤销；文件与目录权限不同分支保留。
     - 分享（`disk-share`，有图）→ 公开分享确认 → 链接／复制 → 完成。
     - 静态资源设置（`disk-static`，有图）→ 开放范围、期限／签名等现有表单 → 确认／取消。
     - 删除 → 原确认 → 回收站；已删除实体显示原“删除节点”，未改语义。
4. 顶部管理入口
   - 已开放静态资源 → 列表／打开／复制／停止等原操作 → 静态设置回指。
   - 查看协同列表 → 自建／受邀 → 定位／打开／成员管理／挂载与移除；已挂载项目回指 D3。
   - 已分享 → 列表／打开／停止分享确认；复用 D3 分享。
   - 回收站（`disk-trash`，有图）→ 路径／列表／空状态 → 恢复、永久删除的原确认流程。
5. 网盘任务
   - 展开／收起 → 排队、上传、下载、失败、取消 → 任务位置／错误信息。
   - 任务气泡 → 恢复任务列表；预览最小化 → 恢复预览。
   - 任务持久性、账号隔离和后台任务行为不由换肤设计改变。

## W · 网页工坊

1. 草稿箱（`workshop`，有图）
   - 创建网页 → 原名称输入 → 编辑器。
   - 导入 `.html.zip` → 系统选择 → 解包校验／错误 → 编辑器。
   - 草稿卡 → 改名、编辑、预览、发布、删除确认。
   - 来源原记录 → 回指 H3；手册 → 现有外部标签页。
   - 关闭／最小化／顶栏恢复 → 原有草稿与编辑位置行为。
2. 编辑器（`workshop-editor`，有图）
   - ZIP 文件名 → 编辑／保存状态。
   - 导入菜单（`workshop-import`，有图）→ 上传／隧道资源管理器／网盘 → 各渠道原选择器 → 回编辑器。
   - 新文件／目录、重命名、删除 → 文本或确认组件；目录树右键菜单复用同一组动作。
   - + Markdown → 原 Markdown 创建和资源处理流程，不新增另一套编辑 UI。
   - 树节点 → 展开／收起／选择／拖动移动；文本内容 → 编辑；二进制内容 → 原有名称与大小展示。
   - 保存／另存为／复制路径 → 原有动作与结果提示。
   - 发布后隐藏框架、全屏浮层打开 → 原选项及含义。
   - 预览当前文件／整个网页 → 预览页 → 返回编辑器。
   - 发布草稿 → 原校验、打包、发布、错误恢复；不改变原引用处理。
3. 隧道网页 ZIP
   - 直接预览 → 网页沙盒 → 创建我的副本／转入草稿编辑／申请权限。
   - 权限申请 → H2 通知中心 → 同意／拒绝 → 原编辑入口。
   - 用户创作的网页本身不被系统换肤覆盖。

## S · 串流控制台

1. 顶层（`stream`，有图）
   - 账号 → D1 全局账号面板；最小化／关闭／恢复 → 原控制台与播放器生命周期。
   - 发现、我创建的、我订阅的、邀请入口、创作者主页 → 同一现有工作区下的列表或输入页。
   - 列表的排序／刷新 → 原筛选结果。
   - 台卡 → 打开观看、订阅／退订、操控、编辑、邀请／可见性、黑名单、归属操作、删除确认、创作者主页，按实际可见权限出现。
2. 创建／编辑（`stream-editor`，有图）
   - 基本设置：名称、封面选择／移除、循环／播完停止、倒计时位置。
   - 手机展开／收起基本设置 → 原有浮层与编辑区关系。
   - 已导入节目项是**排序和管理区，没有导入勾选器**。
   - 每项：起始时刻／停留秒数、拖动、置顶／置底、上下移动、预览、重复加入、移除；本机来源可重新选择文件。
   - 保存 → 校验／时长检查／冲突／成功；返回列表 → 原有未保存处理。
3. 导入（`stream-import`、`stream-selected`，有图）
   - 本机 → 系统多文件选择／句柄权限 → 勾选资源／预览。
   - 网盘 → 账号、分区、路径树、文件 → 勾选／预览；空／错误／受限状态按原行为。
   - 隧道 → 隧道、记录、资源／随机选取等当前控件 → 勾选／预览。
   - 已选择资源 → 按三个渠道分类查看 → 收起（`stream-selected`）。
   - 确认导入 → 原有引用登记 → 返回 S2 的混合节目单；取消 → 原路径。
   - 导入前选择区不增加排序；排序只保留在导入后的节目单。
4. 操控（`stream-control`，有图）
   - 本机预览：暂停本机观看／静音／音量／媒体全屏／时间进度。
   - 节目单：切换节目／等待放送信息。
   - 实际观看设备：原状态与进度／踢出及原确认。
   - 全台控制：上一个、播放、暂停、下一个、停止、来源重试、全局进度、前后十秒。
   - 编辑节目单 → S2；邀请与可见性 → S5；返回列表 → S1。
