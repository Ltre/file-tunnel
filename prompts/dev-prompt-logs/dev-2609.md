【新】问：


    之前已经开发了工具 `tools/change-tgdisk-channel-id.cjs`，用于批量修改网盘数据中记录的 Telegram 托管频道 ID。

    不过现在想到另一个历史兼容问题：以前通过 Telegram Bot 发送到隧道中的文件，部分资源是基于 Telegram 频道的 public `@频道名` 链接进行托管和拉取的。如果以后将该频道改为私有频道，原来的 `@频道名` 将失效，仅靠现有批量修改脚本无法解决这些历史隧道文件的访问问题。

    我考虑增加一个过渡兼容机制，并在 Telegram Bot 配置页增加一个简单的 **Telegram Chat 字典库**，由管理员手动维护 Telegram Chat 的不同标识之间的对应关系。

    字典库至少记录：

    - Chat ID，例如 `-100xxxxxxxxxx`；
    - public `@频道名`，例如 `@example_channel`；
    - 可选的备注/显示名称，方便管理员辨认；
    - 后续如果已有其它 Telegram Chat 标识需要兼容，也可以继续扩展。

    该字典应支持双向查找：

    ```text
    @频道名 → Chat ID
    Chat ID → @频道名
    ```
