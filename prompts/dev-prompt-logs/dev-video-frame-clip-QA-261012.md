    # Drop2Tunnel：视频随机取帧与多媒体收藏管理功能需求

    ## 一、视频随机取帧工具

    ### 1. 视频来源与提取参数

    提供一个 Web 工具，输入 YouTube 视频链接后，即可随机提取视频画面，减少频繁手动截图的操作。

    支持以下设置：

    - **取帧粒度**：设置随机候选帧的时间间隔，例如每 500 毫秒一个候选时刻。
    - **提取数量**：指定每批随机提取多少张画面。
    - **提取范围**：默认整个视频，也可指定一个或多个时间范围，例如 `12:34-56:01,01:02:10-01:05:30`。
    - **时间精度**：支持分秒、时分秒及可选毫秒。
    - **随机规则**：不同范围按有效时长参与抽样；重叠范围合并，避免重复抽取。候选数量不足时明确提示。

    应尽量准确定位视频画面，记录请求的播放时刻和实际解码取得的帧时刻，避免二者混淆。

    ### 2. 提取会话与批次管理

    引入“**提取会话**”概念。

    同一个视频可以建立多个提取会话，也可以多次进入同一会话继续提取，不要求一次完成所有画面的筛选。

    - 每个会话独立管理提取日志、已保存帧及操作记录。
    - 每次执行随机取帧形成一个提取批次，保留该批次的范围、粒度、数量等参数。
    - 同一视频的多个会话可以共享源视频缓存，但各自保留独立的操作历史。
    - 支持重新打开历史会话、继续提取和查看此前结果。

    ### 3. 提取日志与画面保存

    每次提取的画面均可记录到日志，至少包括：

    - 画面缩略图及原图；
    - 精确到毫秒的视频播放时刻；
    - 提取时间及所属批次；
    - 是否已保存的状态。

    日志支持按**视频播放时刻**或**实际提取时间**排序，并可查看、筛选和保存喜欢的画面。

    保存画面与保留提取日志应相互独立。清理未保存的临时帧、删除会话或删除已收藏画面时，需要明确区分数据处理范围，避免误删。

    ### 4. 画面相似度比较与去重

    支持将新提取的画面与以下对象比较：

    - 当前提取会话中的历史画面；
    - 同一视频所有会话的提取日志；
    - 已保存的画面；
    - 用户临时上传的一组参考图片。

    既要检测同一播放时刻的重复提取，也要识别不同时间但画面高度相似的情况。

    相似度可分为快速初筛和精细比较两个阶段。对于完全重复的帧，可以跳过或提示；对于高度相似的画面，应展示比较结果，由用户决定是否保留。

    ### 1. 复用现有视频工具链

    - 缓存身份应区分视频来源、清晰度、音视频轨道及访问身份，避免错误复用或泄露私有资源。
    - 缓存到期后可以清理，但不得影响已经独立保存的画面或短视频片段。

    需要考虑当前网盘单个逻辑文件约 **2000 MiB** 的大小限制。超限时应合理提示或提供可行的替代处理方式。
